# Autoleveller — STM32G431 Sensor Board Firmware

STM32CubeIDE firmware project for the AutoLeveller sensor board used on GEN4 spinning machines ( Draw Frame line). The board reads two analog sensors (scanning/autoleveller sensor and coiler sensor), streams the readings out over UART for debug, and forwards them to the motor board over FDCAN (CAN-FD).

## Hardware target

- **MCU:** STM32G431CBT3 (LQFP48), STM32G4 family
- **Toolchain:** STM32CubeIDE / GCC (project generated from a `.ioc` file with STM32CubeMX)

## Peripherals

| Peripheral | Role |
|---|---|
| **ADC1 + ADC2** | Dual simultaneous regular mode (`ADC_DUALMODE_REGSIMULT`). ADC1 reads the scanning/autoleveller sensor on PA0/channel-mapped input; ADC2 reads the coiler sensor. Continuous conversion, 12-bit, right-aligned. |
| **DMA1 Channel1** | Circular DMA drains the dual-ADC combined result into a 180-word buffer (`adcBuffer`), with a half-complete callback intended to fire around the 90-sample mark. |
| **FDCAN1** | CAN-FD with bit-rate switching, extended IDs, ~500 kbit/s nominal / faster data phase, used to push sensor readings to the motor board. |
| **I2C1** | Configured and initialized (fast-mode timing `0x20C0EDFF`); not yet exercised by application code in this snapshot. |
| **USART3** | TX-only, 7.5 Mbit/s, used to stream `"<autoLeveller>,<coilerSensor>\r\n"` for debug/logging via interrupt-driven transmit. |
| **EXTI (PB1, PA10)** | PB1 is the trigger: rising/falling edge starts and stops the ADC + DMA acquisition. PA10 is also configured for rising/falling interrupts (handler present, currently unused in application logic). |
| **GPIO** | LED1–LED4 (status/debug LEDs on GPIOC/PB9), EXTRA2–EXTRA5 (spare output pins on GPIOA/PB0), Toggle_SW (input, pull-up, PB2). |

## Application flow (`Core/Src/main.c`)

1. `HAL_Init()` → `SystemClock_Config()` → peripheral `MX_*_Init()` calls.
2. Two-point ADC self-calibration for ADC1 and ADC2 (single-ended) before entering the main loop.
3. The main `while(1)` loop is empty — all work is interrupt-driven:
   - **`HAL_GPIO_EXTI_Callback` (PB1):** on rising edge, turns LED2 on and starts dual-mode ADC conversion via DMA (`HAL_ADC_Start(&hadc2)` + `HAL_ADCEx_MultiModeStart_DMA(&hadc1, adcBuffer, 180)`). On falling edge, stops the DMA/ADC and turns LED2 off.
   - **`HAL_ADC_ConvCpltCallback` (ADC1):** unpacks the 32-bit dual-mode result into `autoLeveller` (upper 16 bits, ADC2/slave) and `coilerSensor` (lower 16 bits, ADC1/master), stores them into the shared `SensorTypeDef S` struct, calls `FDCAN_SendSensorvalues_ToMotor()`, and transmits a debug CSV line over USART3.

## CAN / FDCAN layer (`Drivers/CAN_AutoLeveller/`)

A lightweight application-layer module sits on top of the HAL FDCAN driver:

- **`FDCAN.h` / `FDCAN.c`** — low-level FDCAN setup and shared protocol constants:
  - `FDCAN_TxInit()` starts the peripheral, enables the RX FIFO0 new-message interrupt, and pre-fills a default `TxHeader` template.
  - Board addresses (`MOTHERBOARD_ADDRESS`, `FRONTROLLER_ADDRESS`, `BACKROLLER_ADDRESS`, `CREEL_ADDRESS`, `AUTOLEVELLER_ADDRESS`), function IDs (motor state, error, data request/response, run setup/analysis/runtime/diagnostics data, change target, ack, etc.), and priority levels used to build/interpret 29-bit extended CAN identifiers across the GEN4 CAN network.
  - `FDCAN_RxFilterInit()` and `FDCAN_generateIdentifier()` are declared for filter setup and ID construction but are **not yet implemented** in this snapshot — hooks for future work.
  - `RxData[32]` is declared `extern` but has no defining translation unit yet — RX handling is not wired up.

- **`CAN_AutoLeveller.h` / `CAN_AutoLeveller.c`** — the sensor-specific payload:
  - `SensorTypeDef S` — holds `scanningSensor`, `coilerSensor`, and a rolling `sendCounter`.
  - `FDCAN_SendSensorvalues_ToMotor()` builds a 5-byte extended-ID FD-CAN frame (`0xA1E03__<0x0A>` pattern, FD format with bit-rate switching) containing the send counter plus the two 16-bit sensor values (big-endian), and queues it via `HAL_FDCAN_AddMessageToTxFifoQ()` whenever the TX FIFO has more than one free slot.
